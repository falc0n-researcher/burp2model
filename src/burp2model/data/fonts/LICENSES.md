# Fonts embedded in the report

The report embeds these fonts (Latin subset, variable weight) so it renders the same offline.
All three are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).

| JetBrains Mono | The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono) |

Files come from the Fontsource packages `@fontsource-variable/inter`,
`@fontsource-variable/space-grotesk` and `@fontsource-variable/jetbrains-mono`.
