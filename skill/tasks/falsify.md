# Task: falsify — which hypotheses survive scrutiny?

This is the opposite of proving something is vulnerable. For each hypothesis the model raises, try to eliminate it from the evidence. Keep what survives.

## Prerequisite
Build the model and its methodology scaffold ([methodology.md](methodology.md), [../PLAYBOOK.md](../PLAYBOOK.md)).

## For each hypothesis

1. State what would have to be true for it to hold.
2. Check whether the model already contradicts it. Cite the evidence.
3. If the evidence neither confirms nor kills it, name the cheapest observation that would falsify it.
4. Prefer to discard weak hypotheses.

## Produce

- A ranked list of the hypotheses that survived. Only these are worth a researcher's time.
- A short note on what you ruled out, and why.

## Rules
Reason only from the model. Never invent an endpoint, parameter or edge. Cite evidence for every claim. Produce falsifying tests, never payloads. Surviving is not proof of a vulnerability. It means the question is open and worth checking on the wire in an authorised session.
