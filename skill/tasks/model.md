# Task: model — how does this app appear to work?

Describe the app from the capture only. This is comprehension, not assessment.

## Prerequisite
Build the model first ([../PLAYBOOK.md](../PLAYBOOK.md)). Reuse one if it exists.

## Produce, in this order

1. **Shape**: three sentences. What the app is, its hosts and technology, and how big the surface is (endpoints, routes, third parties).
2. **Feature areas**: walk the communities. Name each area and its endpoints.
3. **How it is reached**: for the main areas, the execution flows (entry point, page, script, endpoint). Mark each hop observed or inferred.
4. **Trust**: credential schemes, cookies and flags, which endpoints carried a credential, privileged-looking paths.
5. **Dependencies**: third parties, technology markers, and external-recon facts if present.

## Rules
Mark every line observed, inferred or unknown, and cite the evidence. Never invent nodes or edges. If something was not captured, say so. Output is a map of what the app is, not a list of what is wrong with it.
